# 🎮 Jogos Online

Projeto desenvolvido para disponibilizar uma coleção de jogos online em uma interface simples e responsiva.

## 📋 Sobre o projeto

Este projeto reúne jogos em um único lugar, permitindo que os usuários naveguem, pesquisem e joguem diretamente pelo navegador.

## 🚀 Tecnologias

- HTML5
- CSS3
- JavaScript
- React.js (opcional)

## ✨ Funcionalidades

- 🎮 Lista de jogos
- 🔍 Pesquisa de jogos
- ❤️ Favoritos (opcional)
- 📱 Interface responsiva
- 🌙 Modo escuro (opcional)

## ▶️ Como executar

1. Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

2. Acesse a pasta:

```bash
cd SEU-REPOSITORIO
```

3. Instale as dependências:

```bash
npm install
```

4. Execute o projeto:

```bash
npm run dev
```

ou

```bash
npm start
```
